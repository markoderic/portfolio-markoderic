# Aqua Ribbons

Original vector illustrations authored for this private prototype, Session 14 (2026-09-17). Not original Apple wallpapers, not traced or extracted from Apple artwork. Both files share authored Bézier paths; the dark file uses a separately chosen blue/navy palette. No logo, image texture, font, script, external resource, filter or animation.

Reference direction: layered blue Aqua compositions associated with Mac OS X 10.4 Tiger. Alternative considered: 10.5 Leopard violet aurora/starfield. Reference catalog: https://512pixels.net/projects/default-mac-wallpapers-in-5k/ (accessed 2026-09-17). No external reference image is included in the application; source imagery's reuse terms were not established. The modern light/dark pairing is our interpretation, not a claim about Tiger's theme features.

Runtime: CSS backgrounds imported only through the private prototype's workspace.css. Intrinsic 1600×1000, center/cover in other aspect ratios; fallback colors stay blue during decode or failure. Full provenance, comparison, checks and limits: docs/redesign/58-session-14-desktop-wallpaper-progress.md.
